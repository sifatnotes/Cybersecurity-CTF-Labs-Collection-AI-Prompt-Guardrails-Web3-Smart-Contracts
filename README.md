## Introduction

As modern software ecosystems evolve, securing artificial intelligence interfaces and decentralized Web3 infrastructure has become paramount. AI applications face unique risks such as prompt injection, jailbreaking, and un-sanitized tool calls. Simultaneously, decentralized finance (DeFi) protocols, smart contracts, and digital wallets present high-stakes targets where code flaws directly lead to irreversible financial loss.

This repository organizes hands-on security labs from Learn SecByte into structured learning paths covering AI safety engineering, Web3 vulnerability auditing, and forensic analysis.

## Learning Path

Follow this structured roadmap to master AI prompt security and Web3 auditing:

1. **AI System Prompt Hardening**
   - Learn Secure Prompt Design to mitigate direct jailbreaks.
   - Enforce robust Prompt Guardrails around tool integrations and external APIs.
2. **Blockchain & Smart Contract Foundations**
   - Study Web3 Security Foundations and transaction mechanics.
   - Master Solidity Security auditing, identifying reentrancy and access control flaws.
3. **DeFi Protocol & NFT Exploitation**
   - Audit complex DeFi smart contracts for oracle manipulation and flash loan vectors.
   - Simulate NFT minting attacks and metadata tampering.
4. **On-Chain Forensics & Asset Defense**
   - Perform Ethereum wallet forensics and trace compromised digital assets.
   - Implement Wallet Protection controls for private keys and multi-sig wallets.
